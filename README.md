# Business Intelligence Dashboard

A full-stack Business Intelligence dashboard for analyzing sales data through interactive charts, KPIs, filtering, and report export.

## Features

- Dynamic sales KPIs
- Monthly revenue analysis
- Revenue by category
- Revenue by product
- Revenue vs profit analysis
- Revenue distribution chart
- Category-based filtering
- Reset filter
- Sales data table
- Export filtered sales reports as CSV
- Responsive dashboard design

## Tech Stack

### Frontend
- React.js
- Chart.js
- React Chart.js 2
- CSS

### Backend
- Node.js
- Express.js
- CORS

### Database
- PostgreSQL
